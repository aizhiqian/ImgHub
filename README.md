ImgHub 是一个一站式多平台免费图片上传服务工具，让你轻松上传图片到多个免费图床。

## 📚 功能特点

- 🖼️ **多平台支持**：支持阿里巴巴、京东、网易严选等17个免费图床
- 📤 **简单上传**：拖放文件或选择文件快速上传
- 📋 **便捷复制**：一键复制图片URL、HTML或Markdown代码
- 📱 **响应式设计**：兼容桌面和移动设备
- 🔄 **批量上传**：支持一次性上传多张图片
- 🖱️ **选择性复制**：可选择特定图片生成链接

## 🔧 技术栈

- 纯前端实现：HTML5 + CSS3 + JavaScript
- 无需后端服务，直接连接第三方API
- 使用Font Awesome图标库
- 使用clipboard.js实现复制功能

## 📝 使用方法

1. 选择上传接口（默认为阿里巴巴）
2. 拖放文件到上传区域或点击选择文件
3. 点击"上传图片"按钮开始上传
4. 上传完成后，可以在预览区查看所有图片
5. 点击不同的标签页（URL/HTML/Markdown）查看不同格式的链接
6. 点击预览图片可以选择/取消选择特定图片
7. 点击"复制全部"按钮一键复制所有链接
