<p align="center"><b>ImgHub</b> 多平台免费图片上传服务。</p>

ImgHub 是一个一站式多平台免费图片上传服务工具，让你轻松上传图片到多个免费图床。

## 📚 功能特点

- 🖼️ **多平台支持**：支持 360、搜狗和中国邮政等图床
- 📤 **简单上传**：拖放文件或选择文件快速上传
- 📋 **便捷复制**：一键复制图片URL、HTML或Markdown代码
- 📱 **响应式设计**：兼容桌面和移动设备
- 🔄 **批量上传**：支持一次性上传多张图片
- 🖱️ **选择性复制**：可选择特定图片生成链接
- 🕒 **历史记录**：保存上传历史，随时查看和复制之前的链接
- 🎨 **多彩主题**：支持红色、蓝色、绿色、紫色、橙色和粉色六种主题
- 🌓 **暗色模式**：支持亮色/暗色主题切换，保护视力
- 📊 **数据统计**：查看上传统计数据和使用情况
- 🦊 **极狐 GitLab 图床**：通过 Repository Files API 上传图片并自动生成原图链接
- 🛡️ **上传前鉴权**：极狐 GitLab 上传前校验访问令牌、项目及目标分支
- ⚙️ **接口配置**：在页面顶部的“接口配置”中明文查看直连图床地址及极狐 GitLab 全部配置

## 🔧 技术栈

- 纯前端实现：HTML5 + CSS3 + JavaScript
- 无需后端服务，直接连接第三方API
- 使用Font Awesome图标库
- 使用clipboard.js实现复制功能
- 使用LocalStorage存储历史记录和用户偏好

## 📝 使用方法

1. 选择上传接口（默认为 360 图床）
2. 拖放文件到上传区域或点击选择文件
3. 点击"上传图片"按钮开始上传
4. 上传完成后，可以在预览区查看所有图片
5. 点击不同的标签页（URL/HTML/Markdown）查看不同格式的链接
6. 点击预览图片可以选择/取消选择特定图片
7. 点击"复制全部"按钮一键复制所有链接
8. 点击历史记录按钮查看之前的上传记录
9. 点击主题切换按钮选择不同颜色主题或切换暗色模式
10. 点击数据统计按钮查看使用情况统计
11. 如需使用极狐 GitLab：点击“接口配置”，确认或修改 GitLab 地址、项目 ID、分支和访问令牌，点击“保存并验证鉴权”
12. 在上传接口中选择“极狐 GitLab”，上传前会自动再次验证配置

### 极狐 GitLab 上传规则

- 群组、项目都要设置为公开访问
- 创建 [个人访问令牌](https://jihulab.com/-/user_settings/personal_access_tokens)，勾选 `api`、`write_repository`
- 上传前依次请求 GitLab 的用户、项目和分支接口，确认令牌可用且目标可访问。
- 图片将以 Base64 形式通过 Repository Files API 提交到配置的分支。
- 文件路径、提交消息及 `{year}`、`{month}`、`{fileName}`、`{hash16}`、`{hash32}` 等变量；哈希值按脚本规则基于 Base64 内容计算。
- 上传成功后会生成对应版本的 GitLab Raw 地址；GitLab 13.0 以下实例可在“接口配置”中切换兼容路径。

## 🚀 快速开始

1. 克隆或下载仓库到本地。
2. 将 `index.html` 与 `assets/` 目录原样上传到任意静态托管服务（GitHub Pages、极狐 GitLab Pages、Nginx 静态目录、对象存储静态网站等）。无需 Node.js、数据库或后端服务。
3. 通过站点 URL 打开页面并开始上传。为保证模块脚本和跨域请求行为正确，请通过 HTTP/HTTPS 静态站点访问，而不是 `file://` 直接打开文件。

## 🚀 纯静态部署

本项目没有构建步骤，也不依赖服务端路由。部署时只需保留以下内容：

```text
index.html
assets/
```

以 GitHub Pages 为例，将仓库推送后在仓库设置中把 Pages 来源设为目标分支的根目录即可。极狐 GitLab Pages、任意对象存储或 Web 服务器的静态站点配置方式相同。

极狐 GitLab 上传由浏览器直接调用 GitLab API，因此部署域名必须能被目标 GitLab 实例的 CORS 策略允许。若实例拒绝跨域请求，纯静态站点无法绕过该浏览器限制，需要在 GitLab 实例侧开放 CORS。

## 🔍 其他说明

- 图片上传到第三方服务器，请勿上传敏感、违规或侵权内容
- 图片保存时间取决于各图床平台策略，建议重要文件做好备份
- 部分接口可能会有频率限制或不稳定情况
- “接口配置”按需求以明文展示并存储极狐 GitLab 配置。纯静态页面无法将令牌变成服务端私密信息；请仅在允许公开该令牌的部署场景中使用。
